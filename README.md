# Steam 花费统计器 (SteamSpend)

---

##  快速开始

```
┌─────────────────────────────────────────────────────┐
│  1. 双击 SteamSpend.exe                             │
│         ↓                                           │
│  2. 程序自动尝试读取你浏览器的登录信息              │
│         ↓                                           │
│      读到了？  ────────────→  直接显示统计结果     │
│         ↓ (没读到)                                  │
│  3. 按程序提示，手动复制 2 个值粘贴进去             │
│     （下面有详细步骤，跟着做就行）            │
│         ↓                                           │
│  4. 显示统计结果                                   │
└─────────────────────────────────────────────────────┘
```

---

##  方式一：自动获取
程序会自动从你电脑的浏览器里读取 Steam 登录信息。

**适用情况**：你的浏览器（Edge/Chrome/Firefox）**登录过 Steam 网页版**，
且浏览器版本较旧（或使用 Firefox）。

**操作**：双击 `SteamSpend.exe` → 等着 → 看结果。

> **为什么有时候自动读取会失败？**
> 2024 年之后的新版 Chrome/Edge 采用了更严格的加密（v20），
> 程序无法读取。这是浏览器的安全升级，不是程序坏了——
> 遇到这种情况，直接走下面的**方式二**，照样能用。

---

## 方式二：手动获取

**什么时候用**：自动读取失败时。程序会弹出提示，你按下面步骤把两个值
复制粘贴给它，全程约 1 分钟，**不需要任何技术知识**。

### 第 1 步：登录 Steam 网页版

打开浏览器（Edge 或 Chrome 都行），访问：

```
https://store.steampowered.com
```

用你的账号登录。

### 第 2 步：按 F12 打开开发者工具

在 Steam 页面里，按键盘上的 **F12**（笔记本可能要用 **Fn + F12**），
屏幕右侧/下方会弹出一个新面板。

> 如果 F12 没反应：鼠标**右键点页面任意位置 → 选"检查"**，效果一样。

### 第 3 步：找到 Cookie 面板（文件夹里有示例图片，找不到可以参考）

在弹出来的面板顶部，找到并点击 **"应用"** 标签
（英文界面叫 **Application**，可能要点 `>>` 展开更多标签才能看到）。

然后在**左侧菜单**里找到 **Cookie**，点开它，
再点击下面的 **`https://store.steampowered.com`**。

### 第 4 步：复制第 1 个值（steamLoginSecure）

右侧会出现一列表格。找到名为 **`steamLoginSecure`** 的那一行：

- **双击**它"值"（Value）列里的内容，会自动选中
- 按 **Ctrl + C** 复制
- 回到程序窗口，在"steamLoginSecure 的值"后面 **Ctrl + V 粘贴**，回车（运行steamspend.exe自动捕捉失败后会让你输入）

### 第 5 步：复制第 2 个值（sessionid）

再找到名为 **`sessionid`** 的那一行，**重复第 4 步**：

- 双击值 → Ctrl + C → 回到程序 → Ctrl + V → 回车

### 完成！

程序开始抓取你的交易记录，稍等几秒，就会显示统计结果。

---


程序会显示这几行：

| 项目 | 含义 |
|---|---|
| 总交易笔数 | 你所有的 Steam 交易次数 |
| 总支出（余额减少） | 从钱包/支付宝/微信等花出去的所有钱 |
| 人民币 / 美刀 / 港元 | 各币种分别花了多少 |

##  常见问题

**Q1: 提示"登录信息无效或已过期"？**
Steam 登录态约 2 周过期。重新打开浏览器登录 Steam，再走一次"方式二"复制新值。

**Q2: 卡在"正在连接"或报网络错误？**
说明电脑访问不了 Steam。请开加速器/梯子（**全局模式**），再重试。
如果程序支持代理参数，可以运行：
```
SteamSpend.exe --proxy http://127.0.0.1:7890
```
（把端口换成你加速器的实际端口）

**Q3: F12 打开了但找不到"应用"标签？**
点面板顶部标签栏末尾的 **`>>`**，更多标签里一定会有"应用"。

**Q4: 表格里没有 steamLoginSecure？**
说明你还没登录成功。确认第 1 步登录完成、且当前页面是
`store.steampowered.com`，然后按 F5 刷新页面再看。

**Q5: 这个程序安全吗？会偷我密码吗？**
程序**从不接触你的密码**。它只需要浏览器里已经登录的"会话凭证"
（类似一张已签到的入场券），并且**只在你的电脑本地使用**，
不会上传到任何地方。源码完全开源，可自行审查。
